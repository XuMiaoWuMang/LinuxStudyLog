## 定时器

OS会负责定时器的维护，当定时器到期时，OS会向进程发送一个SIGALRM信号。

`int alarm(int seconds);`

- 返回值：返回0表示成功，返回-1表示失败，如果。
- 参数：seconds表示定时器到期后，向进程发送SIGALRM信号的时间间隔，单位是秒。
- 功能：设置一个定时器，当定时器到期后，向进程发送SIGALRM信号。

取消则使用`alarm(0)`即可。
- 返回值：定时器剩余的时间，单位是秒。
- 功能：取消定时器。
 
### 模拟定时器管理

首先定时器肯定是一个结构体，因为需要记录信号发送的对象，同时还需要记录自己什么时候到期。

```c
struct Timer {
    pid_t pid;// 记录哪个进程申请的定时器
    time_t expire_time;// 本质是时间戳，记录定时器到期的时间
    struct Timer* next;// 指向下一个定时器的指针
    func_t handler;// 处理方法，如果有程序里signal()函数的第二个参数，则按signal()函数的第二个参数处理，否则按默认处理
}
```

由于定时器的数量是没有限制的，所以使用链表管理，但是链表是没有办法知道哪个定时器先到期，所以需要使用最小堆。判断定时器是否到期，只需要判断堆顶是否到期就行。

### 实际应用

在MyAlarm.cc中，我们事前设定好四个任务和一个定时器，当定时器到期时，向进程发送SIGALRM信号，然后进程会调用对应的处理函数handler，handler函数中我们会依次处理四个任务，实现记录日志功能（实际开发中，只需要把对应的写、读、保存和关闭的代码替换匿名函数里的代码就行）。那么每过一秒，进程就会顺序执行四个任务，记录日志。

如果把alarm换成硬件中断，这就是一个mini版的OS。
