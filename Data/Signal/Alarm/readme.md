## 定时器

OS会负责定时器的维护，当定时器到期时，OS会向进程发送一个SIGALRM信号。

`int alarm(int seconds);`

- 返回值：返回0表示成功，返回-1表示失败，如果。
- 参数：seconds表示定时器到期后，向进程发送SIGALRM信号的时间间隔，单位是秒。
- 功能：设置一个定时器，当定时器到期后，向进程发送SIGALRM信号。
